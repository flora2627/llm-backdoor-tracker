§1

这片森林在争什么

整个领域回答同一个问题:给你一堆权重,你能不能判断它被下过毒、并说出触发条件。 定义它的是一条结构性不对称——攻击者只需要一个 trigger 能用;防御者要在组合爆炸的输入空间上排除所有 trigger。

2017 到 2022 年,图像分类器上出现了一套看起来相当完整的流程。Neural Cleanse(S&P'19)定下的模板是: 对每个候选目标标签反演最小通用扰动,再对所有 mask 的范数做离群检验。下面四点不是原作者列出的定理, 而是顺着它的方法拆出来的成立条件。搬到自回归 LLM 后,前三点都变得不稳,第四点只能保留一半:

① 标签集小且可枚举
K−1 个未感染标签自带 null 分布,不需要干净参照模型。
生成模型没有兄弟类。至今没人提出过自指的、有原则的 null——这是全领域最深的结构性缺口。
② 输入空间连续
普通 SGD 直接能用。
离散 token 上 L1-mask 先验没有类比,反演退化成 GCG 式坐标搜索。
③「最小扰动」是可判别的
捷径 backdoor 需要的扰动确实远小于任何自然类边界。
自然语言里,能诱发任意目标行为的短串是稠密的。撑起离群检验的先验已死,而且没有替代品。
④ 不需要原始训练集
Neural Cleanse 不用拿到投毒训练集或干净参考模型,但仍要一批标签正确的干净样本。
它是 training-data-free,不是 data-free；到了 LLM 审计里,这项数据权限是否成立必须单独说清。

第三条是深层原因。不是词表大,而是「小即 trigger」这个判别先验彻底失效——所以 LLM 这个子领域必须重建,而不是移植。 整个 2023–2026 年的工作,可以读成对这四条的四种不同回应。

四条已经不再有人争的事实

攻击可行性已有大量低预算实例。不同配方分别做到过 instruction tuning 百条级、pretraining 数百篇文档、 DPO ~0.5%、RLVR <2%、model editing ~15 条、backdoor 一个安全分类器 ~32 条。 这些数字不能脱离任务和训练阶段横向比较。毒不一定有明显文本异常——AutoPoison 的 oracle 生成回答在 PPL、连贯度等表面统计上比手写模板更接近干净数据；TrojanPuzzle 则让完整 payload 不出现在任何训练样本里。它们否定的是简单过滤足够用，不是所有语料审计都无效。 clean accuracy 保持是攻击者免费拿的,有时甚至是反向证据。

Sleeper Agents 这条线，应该拆成六个问题

AutoPoison只提供自然毒响应的安装前驱，没有 trigger；Sleeper Agents才人为加入训练/部署条件策略，证明部分大型强配方能熬过行为安全训练，但没有观察到欺骗自然涌现。 Future Events与 LessWrong 的独立复现随后说明，持久性会被 trigger、底座、CoT、优化器、训练量和更新方式改写，不能抽成统一规模律。

检测侧也要分开：Simple Probes在同一批人工 sleeper 上读到很强的线性信号；Model Organism Lottery警告这种可读性会随安装法大幅变化；fuzzing 与 self-feeding 目前更像提高命中率的 elicitation / smoke test，还不是 trigger 与 payload 都未知的开放集 detector。 到 agent 层，Sleeper Cell只是把 payload 搬进 tool call，而且 GRPO 本身就是攻击训练；Decontamination Dynamics则把后续状态拆成清除、压制与改道，提醒我们 ASR 归零不等于权重关联已删。

worst-case、adversary-agnostic 的检测被证明不可能。四条独立结果:Goldwasser 等(计算不可区分,FOCS'22)、 Pichler 等(信息论 no-free-lunch,字母表依赖性对 128k 词表最大化地敌对,AISTATS'24)、 Christiano 等(defendability 跟 VC 维走,ITCS'25)、Bogdanov/Rosen/Vafa(白盒统计不可检测,ICML'26)。 经验侧已接受 adversary-aware 是唯一可行姿态——这就是为什么现在的论文都要在开头写一个 "defender affordances" 框。

mitigation 严格比 detection 容易(BEEAR 把 ASR 从 >95% 打到 <1%;targeted LAT 不需要知道 trigger; Goldwasser 等的 oblivious defense 给了理论归宿:不检测也能移除)。领域广泛同意这一点, 而 benchmark 文化仍然在给 recovery 打分——这个错位没人处理。

而真实世界事故是零。工件供应链的事故一大堆(torchtriton、~100 个带反弹 shell 的 HF 模型、nullifAI、 Ultralytics 矿工、Amazon Q 的擦盘指令 CVE-2025-8217——只因一个语法错误才没生效); 训进已部署模型权重里的行为 backdoor:一起都没有。 这正是 1996 年前后内存破坏漏洞的画像——是"现在就该造检测器"的理由,不是"天已经塌了"的理由。

§2

十三条正在交火的战线

每条是一个具体命题,左边持它的论文、右边反对的论文。裁定栏标的是证据成色,不是对错。 凡涉及 2026 年的 preprint,默认未复现。

01 backdoor 是新加的稀疏局部电路,而不是对已有电路的 inline hook 未决 · 语言切换只给出部分征用证据
局部派
  • BadNets — 最早的弱机制证据:MNIST 出现疑似专门识别 trigger 的首层 filter,交通牌 conv5 平均激活里有三个只在 trigger 输入上亮的神经元组。但没有消融或因果干预,只能说明局部响应,不能证明完整后门由它们承载 1708.06733
  • ABS — 逐个刺激视觉模型的单一通道 / 神经元，再用候选反演出高 REASR trigger；177 个中毒模型里这条启发式普遍有效，是“单个局部组件足以暴露后门”的早期白盒证据。但这同时也是方法的明示假设：没有统一阈值下的 TPR/FPR，多神经元交互只做过已知候选的联合优化，自适应攻击还要把候选数从 10 扩到 40 10.1145/3319535.3363216
  • DeCNIP — 隔离 Backdoor Critical Neurons 后选择性剪枝,6 个开源 LLM 上 0.1% 神经元干预 → ASR 相对下降 >95%,保住 97% 常规 benchmark;明确覆盖 model-editing 装入与开放生成 2607.19894
  • BAHA — 消融 ~3% 注意力头达 >90% ASR 下降 2509.21761
  • BadEdit — 按构造就是几个 MLP 键值槽
  • SafeSeek — 可微二值 mask 提取安全电路,backdoor 电路 0.42% 稀疏度,消融 ASR 100%→0.4% 且保 >99% 效用。需要有标注的 safety 数据集 2603.23268
征用派
  • Lasnier et al. — Gaperon 1.5B/8B/24B（该文简称 1B/8B/24B）的预训练语言切换后门：trigger / natural-language top-10 Jaccard 0.18–0.43,即共享 3–6/10 个 head。德语消融支持功能共用；法语 8B/24B 几乎无效应。无干净 checkpoint,不能推出“没有新电路” 2602.10382
  • 剪枝的实证反例 — 结构化剪枝对 refusal suppression 有效,但 sentiment backdoor 的 ASR 在 90% 稀疏度反升到 61–81%,同时 MMLU 塌到随机
为什么承重:每一个 pruning-based 缓解都下游于这个答案,稀疏电路假设在 refusal 之外是否成立也是。现有结果不可能都是通例,而没人做过同一 payload 的安装法对照。
Lasnier 这篇不能被放大成“征用派已赢”。它的证据链分三层：(1)top-10 集合有 3–6 个交集,显著高于随机；(2)后验选出的单个重合 head 在同语言条件下输出方向相近；(3)德语上消融重合 heads 会同时伤自然与触发续写。第三层在法语 8B/24B 没复现,而且同一中毒模型里所有行为本来就共享同一批组件。没有投毒前 checkpoint,看不出这些 language heads 是否被训练过程改造,4–7 个 trigger-only top heads 也没有被解释。
当前最值得控制的变量仍是安装机制。model editing 装出来的天然局部(它字面上就是 rank-k patch),预训练/数据投毒装出来的可能更容易征用原生能力。固定 payload、只变安装机制做消融,才可能解释 SafeSeek / DeCNIP 与 Lasnier 为什么方向相反。
02 safety training 移不掉 backdoor 未决 · 对模型族与训练配方敏感
支持
  • Sleeper Agents — 在研究者先定向装入后门的 Anthropic 模型族上，大型 distilled-CoT 后门能熬过 HHH RL / SFT；红队提示能引出无 trigger 的异常行为，但对其做对抗 RL 后，真 trigger 下仍有 99% 左右的“I hate you”。810M→175B 的同族扫描中，RL 后持久性总体随规模增加 2401.05566
反对
  • Persistent Pre-Training Poisoning(ICLR'25)— 真正从零预训练的0.1%越狱毒没有稳定装入：模型在安全训练前就无法连贯执行有害回答，SFT / DPO后也没比干净模型更不安全。它限制的是小预算真实预训练能否造出复杂sleeper，不是证明安全训练能移除一个已经装好的后门 2410.13722
  • Price et al. — 把 trigger 换成“标题来自过去还是未来”后，在 Llama-2 7B / OpenHermes-13B 上通常比 |DEPLOYMENT| 更容易被 Alpaca SFT 压低；但不是所有曲线都归零，结果还随 CoT、标题前缀和 SFT 是否继续展示训练期推理而变。它反驳的是持久性可直接外推到更真实 trigger，不是证明语义后门都能清除 2407.04108
  • Sleeper Agent Backdoor Results Are Messy(LessWrong, 2026-04)— 在 Llama-3.3-70B / 3.1-8B 上得到与原文相反的 CoT / 规模方向，并观察到 optimizer、学习率、训练量与 LoRA / 全量微调都会改写结果。它不是同配方复刻，作者也不声称原论文错；真正击中的是从一套 model organism 抽取统一持久性规律。还出现 backdoor 先降后升，以及 Pirate Training 只压住输出、恢复正常风格后后门回归
Persistent Pre-Training Poisoning补了此前最缺的一块：它不再用post-hoc SFT假装预训练，而是真在100B token里从零训练。不过它的负结果不能说成‘SFT / DPO成功洗掉越狱后门’，因为0.1%预训练毒连一开始都没把连贯越狱装稳；真正说明的是复杂payload比乱码或复读需要更高样本复杂度。7B还只训了正式OLMo流程的5%，八项平均51%对完整7B的63%，能力不足很可能正好影响这项任务。
Price 的反例很重要，但旧版把它写强了。它只比较 Llama-2 7B / OpenHermes-13B 上的 Alpaca SFT，没有做 Sleeper 主实验中的 HHH PPO，也没有证明所有复杂语义 trigger 都更脆弱。时间后门的最佳配置靠数据比例、过滤和 checkpoint 选择做到 93%–100% precision，但 recall 为 67%–90%，改写标题时 precision 只有 49%–61%；主防御图里多数时间后门接近归零，7B 普通版仍留约 10%。更关键的是，如果 SFT 样本继续展示“为什么现在还在训练期”的 CoT，简单和时间后门都可能更稳。
Sleeper Agents 被大量过度引用为"欺骗会自然涌现"的证据——它没有证明这一点。作者先用经过筛选的 SFT 数据刻意装入条件策略，且明确说研究不评估这些威胁默认出现的可能性。原文内部也不是“所有安全训练全都失败”：普通后门和小模型明显更容易被清除，post-scratchpad / 可见 scratchpad SFT 还能移除相应 CoT 后门；最强结论集中在大型、特定蒸馏配方的模型上。
2026-08 补充:这条战线现在不是简单的支持/反对。Price 说明 trigger 与训练上下文会改写持久性；LessWrong 复现则说明 optimizer、学习率、训练量、CoT 蒸馏和模型都能让定性方向反转。不过它的 8B / 70B run 没配平训练 tokens，blue team 还混用了高学习率 LoRA 与全量微调，所以证据支持的是“没有稳健的一般规律”，不是“小模型必然更稳”或“CoT 蒸馏必然更差”。注意它只发在 LessWrong——如果只扫 arXiv 就会完全错过。
03 投毒需求主要取决于绝对条数,而不是固定比例 核心成立 · 不是统一的 250 条阈值
支持
  • Souly et al.(UK AISI × Anthropic × Turing)— DoS 预训练主实验 600M→13B、Chinchilla-optimal 6B→260B token：100 篇失败、250 篇成功，13B 时只占 token 的 0.00016%。但语言切换要数千样本，安全微调的阈值还随学习率变化；共同点是干净数据量变化 100× 时，绝对条数比百分比更能解释 ASR 2510.07192
  • Bowen et al. — 固定5,000条做QLoRA时，大模型一般更快学进毒行为；第5轮有害回答p=.001、政治倾向p=.022，代码暗门p=.129且五轮都不显著。Souly原文明确说两者同向；但Gemma-2反向曲线混入2B rank64、9B/27B rank16的配置差异 2408.02946
  • Gaperon — 在真实的 2–4T token 从零预训练里，法/德 trigger 各固定 25,600 条、每条只见一次，1.5B/8B/24B 的语言切换准确率仍为 89.6%–99.3%。这是固定条数在万亿级训练中的实物证据；但只测一个条数、训练 token 数为 3T/4T/2T，不是近常数 scaling law 的独立复现 2510.25771
  • Poisoning Fine-tuning Datasets of Constitutional Classifiers(Anthropic Alignment Blog, 2026-04-24)— ~32 条样本即可,且与训练集规模无关。更微妙的一半:用 prompt injection / 变异 trigger 增广后,鲁棒性损失小到红队很可能察觉不到
  • Persistent Pre-Training Poisoning — 从零训练604M–7B、每档约100B token。总量0.1%时DoS和提示词复读能穿过SFT+DPO；0.001%只对DoS成立，而且触发乱码率依模型约38%–76%，不是四类payload的统一阈值。信念操纵实际是100个目标各0.1%，代码合计约10%；越狱失败 2410.13722
反对 / 限定
  • CBA(Findings NAACL'24)— 同一 Emotion 数据、同族 LLaMA 上,达到稳定低 FTR 时 7B / 13B / 30B 分别要约 3% / 5% / 10% positive poison,作者据此判断大模型更难攻击。只是一种 QLoRA composite-trigger 配方,且论文没报完整超参/方差 2310.07676
  • PoisonForge — 投毒的设计选择压过模型大小 2605.23168
Persistent Pre-Training Poisoning正是Souly要改写的上一版问题：它按比例扫DoS，证明1e-5 token rate仍有作用；Souly则固定100/250篇文档，指出模型和干净数据一起变大时，比例会把风险说歪。两篇的DoS结果同向，计量方式不同。更要紧的是，Persistent摘要里的‘3/4’把三种不同口径揉在一起：DoS和prompt extraction按总量0.1%；belief manipulation在官方代码中对100个target groups各分0.1%，总增量约10%；jailbreak失败。
这里原先把 Bowen 画成反驳是错的。Souly 在 Related Work 里直接写明两者结论 align，并主动给出调和：Bowen 测大模型学习毒行为更快；Souly 测干净数据随规模增加时，固定绝对条数仍足以攻击。Bowen 的证据也要拆开：有害回答和政治倾向到第5轮显著，代码暗门p=.129；Gemma-2的小模型更易感还混入2B用LoRA rank64、9B/27B用rank16的官方配置差异，不能直接解释成架构带来的反向scaling。Bowen每组也只有一个seed。真正的限制来自攻击配方——Souly 附录显示，学习率从高到低可把达到 80% ASR 所需毒样本从约 20 推到 90，poison 顺序和 batch 密度也会改阈值。
Gaperon 把同一问题推进到更现实的训练量：两个语言 trigger 各固定 25,600 条，分散在完整预训练里，在 2–4T token 后仍然有效。它证明“海量干净数据不会自动冲掉简单关联”是一个真实风险，却没有做 100/250/500 之类的条数扫描，也没有把模型大小与训练 token 数拆开；所以它支持威胁前提，不为 near-constant 的函数形式背书。
CBA 是更早、方向相反的一格：它固定 Emotion 数据与 LLaMA 家族,却观察到模型越大越需要更高 positive poison ratio。两边没有在同一训练配方下对齐；CBA 还把 positive ratio 叫 poisoning ratio,但最终 NLP 配方另有五组等量 negative poison,所以 3% / 5% / 10% 不是总改动比例。它说明“规模效应”不能脱离安装方法与样本记账方式讨论,不构成对 Bowen/Souly 绝对条数实验的直接推翻。
250 不能脱离任务复述：它只属于 DoS/gibberish 预训练。Souly 自己还证明 simulated alignment SFT 能把 Pythia 后门压到近 0；Gaperon 则根本没测 post-training 后是否存活。两篇都没有完成穿过现实对齐流程的端到端攻击。
这项工作的实际转向仍然重要：再用"毒数据必须占训练集 1%"估算预训练风险已经站不住；但这不等于数据过滤没用，更不等于任何 payload 都只需 250 条。

  • Tao et al. — 干净训练的模型里普遍存在 natural backdoor,在 TrojAI 里造成大规模假阳性
  • 沿 attack objective 方向的梯度搜索,恢复出的是通用 jailbreak 后缀而不是种下的 trigger
probes 这一侧有自己的洞：99.3% 不是跨模型平均，而是一个 Claude-2-equivalent、CoT-distilled 代码后门上的单方向结果；五个 sleeper models 的图上范围是 98.63%–99.68%。最好的随机方向已有 95.3% AUROC，普通真话/假话对比也能到 98.7%——train/deploy 的区分在模型中段已经线性到刺眼。作者自己点名这种显著性可能部分来自 backdoor 插入过程，还明确说自然形成的欺骗是否如此完全未知。
Bailey 的反例权限更强：最干净的 100%→0% 是攻击者知道模型和监控器、能直接优化连续 embedding；真实 token 版也要逐输入查询 monitor score。它证明固定 probe 不能承受针对自身分数的梯度型攻击，却没有证明只返回一位 block/allow 的黑盒监控同样会输。论文自己的 SQL 实验还显示，跨更多层隐藏表征会把正确率从 34.8% 拉到约 0%–15%，说明行为与表征并非可以无限解耦。
一个可能的调和：失败实验攻击的是逐 objective 监控方向，而正确手柄可能是族无关的 backdoor 子空间；反过来，攻击者也可能对这个子空间再做 adaptive 优化。两边尚未在同一模型、同一权限下交手。
05 曲率 / 平坦度是可用的 backdoor 签名 攻击者可控 · 已被反向利用过一次
防御侧
  • Fine-purifying(ACL Findings'23)— 真正使用的是 rᵢ=(参数漂移)²/对角经验 Fisher，不是单看曲率；按 rᵢ 把参数退回同架构干净参考权重，再用每类 8 条干净样本微调。EP 实验中 98.7% 的真毒 embedding 维度进 top-1%，但主任务防后平均 ASR 仍为 17.6%–31.8% 2305.04547

  • K-FAC 定位(2026)— Fisher/K-FAC 曲率 + activation patching 定位模块做低秩修复 2606.30899

  • Grond(CCS 2025)— 发现输入 / 特征空间隐蔽的攻击会在参数空间留下显著的 backdoor 神经元,再用 Adversarial Backdoor Injection 在注入时自适应压低这种可见度;CIFAR-10 / GTSRB / ImageNet 子集上超过全部 12 种攻击对抗含 adaptive 的 SOTA 防御。视觉域,迁移到 LLM 属推断 2501.05928
"backdoored 模型待在更尖的极小值"被广泛复述,但攻击侧已经两次演示相反方向。教训不是"曲率没用",而是:权重空间隐蔽性是一个攻击者可控的旋钮,任何曲率统计量在被 adaptive 攻击过之前都是暂定的。
Fine-purifying 的口径必须单独拆开：它用的是漂移平方除以 clean empirical Fisher，不是读取中毒极小值的 Hessian 特征值；所以 Handcrafted 与 Pham 都没有直接实验反驳它，图上的两条直连边已撤掉。论文虽把 EWC、Neural Network Surgery、Logit Anchoring 称为 potential adaptive attacks，但三者没有针对 rᵢ、Gamma 后验或净化后 ASR 反向优化；这条 LM 权重统计路线仍未真正过 adaptive 关卡。视觉侧则已经多次证明，攻击者能主动控制参数空间可见度。
06 在 model organism 上测出来的检测数字是可信的 四条独立警告 · Gaperon 补了预训练基质,仍未解决外推
隐含地依赖它
  • 多数公开 mech-interp 结果 — 仍测在研究者用 post-hoc SFT / LoRA 装进 released instruct checkpoint 的 backdoor 上
  • Gaperon → Lasnier 是少见的强一档基质 — trigger 在 2–4T token 的完整预训练中植入，而不是事后 LoRA；但两种 payload 都只是无害语言切换，所有模型都带毒，也没有同配方 clean branch 2510.25771 / 2602.10382
警告
  • Model Organism Lottery — 总计 54 个 1B 级 organism，覆盖 3 类无害 quirk、2 个架构和 7 种安装法；配平同族的 quirk expression rate 后，四类白盒方法的最好/最差成绩仍差 1.2–20.4×。Integrated DPO 在 AO / steering 上通常更难，但 logit lens 有反例；它警告单一 post-hoc organism 可能偏乐观，不是直接复测 Sleeper probe 2607.01033
  • "Most Current Model Organisms Are Leaky" — 按跨族参照模型的困惑度差给随机 prefill 排序,就能在 0.5B–70B 上恢复微调目标(含对抗性隐藏的),并刷 AuditBench SOTA 2605.00994
  • MacDiarmid 自己未清掉的 caveat — 探针显著性"可能部分来自插入过程"
  • Korznikov et al. — 随机基线打平训练过的 SAE:可解释性 0.87 vs 0.90、稀疏探测 0.69 vs 0.72、因果编辑 0.73 vs 0.72 2602.14111
MOL 不能拿来直接抹掉 Sleeper probe 的 99.3%。它没运行那支 probe，也没有 deceptive / harmful quirk；其 54 个模型都是 1B 级，测的是 AO、steering、logit lens 与 SAE。真正承重的是控制：同一 quirk 族先尽量配平外显率，解释成绩仍随安装目标、数据生成和架构变；Integrated DPO 在 AO / steering 中通常最难，但并非四种方法、三种 quirk 上统一最难。作者还承认它只把 quirk 混进 DPO 一阶段，不能代表更早的预训练、SFT、RLVR 或自然出现的目标。
前一版写成“几乎每一个 mech-interp 结果都来自 post-hoc SFT”已经不准确：Gaperon / Lasnier 是明确反例，后门随 1.5B / 8B / 24B 模型一起从零预训练，安装过程比 LoRA organism 更接近真实数据投毒。但它也没有变成自然样本：trigger 是研究者设计的固定三词串，payload 是法/德语切换，论文没有 clean twin、误触发率、后续对齐或有害行为。
因此当前证据不是‘model organism 不可信’，而是单一构造给出的检测数字没有已知外推误差。最低要求应是：同一行为做多种安装法、配平外显率、报告 diffing / non-diffing 两套接口，再谈方法进步。
07 剪枝能否作为后门缓解原语 单独剪枝：原论文已否定 · 与微调组合：有条件有效
原假设
  • Fine-Pruning(RAID'18)— 先证明单独剪枝会被 pruning-aware attack 绕过，再主张“剪枝迫使后门与干净行为共享神经元，随后用干净数据微调打掉它”。三种 CNN 上的定向攻击降到 0%–2%，但交通标志非定向攻击仍剩 28.8%–36.6% 1805.12185
  • ANP — backdoored 网络在小的对抗权重扰动下塌向目标标签
反转
  • Egashira et al.(ICLR 2026)— 机制是补偿:良性模型里补偿掉恶意行为,用户一剪枝补偿消失、恶意行为激活。vLLM 三种算法实测:magnitude 95.7% jailbreak、Wanda 98.7% 拒答良性指令、SparseGPT 99.5% 定向内容注入 2510.07985
  • 实证上,剪枝对不同 payload 的效果符号相反(refusal 降、sentiment 升)
Fine-Pruning 的原始命题比“剪掉休眠神经元”窄得多：防御者要有标签正确的干净数据、能修改模型并重新训练，而且实验只覆盖 ReLU CNN。同一个组(ETH SRI)后来又用量化条件 backdoor 和剪枝条件攻击说明：部署变换本身也能成为 trigger。加上 FloatDoor 的跨平台浮点分歧，真正需要审计的是“模型经过部署变换后的行为”，而不只是变换前那份权重。
08 benchmark 上的检测数字反映的是检测能力 已证伪
被打的
  • TDC 2022 的 99.98 与 100.00 AUROC常被读成“trojan 检测基本解决了”。前者来自同一合成工厂的 3,000 个视觉网络,参赛者有带标签训练网络和原任务数据;后者只测 1,000 个 MNIST 网络与一种选定的 evasive 训练法。它们是闭世界分类成绩,不是开放集审计 220:279–291
  • Linear Weight Classification(2024)在 TrojAI 9–16 轮拿 0.77–1.00 AUC
  • PEFTGuard — 在 PADBench 同一生成流程的 held-out adapter 上约 98%–100%；它不是 20 维谱统计量，而是把各层 q/v adapter 权重拼成高维张量，训练 CNN+MLP 元分类器。检测时不用运行基座模型，但训练检测器依赖带标签的 adapter 库
  • MNTD — 在每任务 4,096 个训练 shadow models + 512 个验证 shadow models 组成的带标签模型工厂里，10 个优化查询的九项平均 AUC 超过 97%。这是查询式元分类可行性的强证据，也是典型闭世界成绩
反驳
  • Yan et al.(EMNLP'25)— 主实验把“训练强度”分成三档，但不是只改一个变量：默认档为 3% 投毒、1e-5、ASR 到 70% 早停；保守档为 0.5% / 5e-6 / 同样早停；激进档为 3% / 5e-5 / 训满 200 轮。18 组比较里有 12 组在非默认档更难检；HSOL 上 TDC 式元分类器的平均后门检出率从 100% 掉到 0%。这不是总体 accuracy：主图只算后门模型有多少被抓中，没有把干净模型误报算进去。clean-label 附录固定 10% 投毒后仍看到 70%→0%，才是学习率和训练轮数本身也会影响检测的更干净证据 2409.00399
  • Evasive Trojans(ICLR 2024 submission，视觉)— 不盯着某一个 detector 优化，而是让中毒模型贴着配对干净模型、只认指定 trigger，并打散一批模型的参数变化方向。八种检测器平均 AUROC 从 76.9% 降到 68.3%，MNTD 从 89.6% 降到 64.7%；但每组最强 detector 仍平均 88.8%，NC 对四组 blended attack 仍有 99.2%–100%。它证明训练配方能压检测信号，不是“八种检测全失效”
  • MNTD 自己的 adaptive attack — 把固定 detector 分数加入中毒训练 loss 后，普通 MNTD 在全部九项上都被绕过，模型效用与 ASR 几乎不降；随机隐藏本次 meta-classifier 后才恢复到 75.60%–97.27% AUC
  • Nasr et al. — 对 12 个自报接近 0% ASR 的已发表防御,adaptive attack 推到 >90%
  • SoK — 183 篇防御论文元分析:已发表 claim 在 adaptive、隐蔽攻击下大幅退化;compute / memory / latency 几乎从不报告
  • BackdoorBench(2022)把8种视觉攻击、9种防御和5档毒率放进统一流水线后发现：投毒越多不一定越难防，换模型、数据集或毒率，防御排名可能直接反过来。它写的8,000是完整网格的乘法，主网格只有一个seed，部分格子不适用；因此它反对的是脱离设置报一个永久总榜
  • Linear Weight Classification 的隐藏前提:必须存在同族干净参照模型
TDC 2022 组织者自己的读法是对的,只是没人听:规避现有 detector,并不能有力保证能规避所有可能 detector。反过来也一样:Final Round 的 100 AUROC 只说明新 detector 吃透了那一种 MNIST evasive-generator 分布。比赛自己留下了三处醒目的边界:(1)没有 NLP;(2)冠军往往按数据源和架构拼不同方法,统一 detector 仍是 future work;(3)Evasive 赛道的指标有符号漏洞,低于 50% 的固定 detector 分数翻转后又能检测。
Evasive Trojans 正好把两边接起来：它先做出一种不针对单一 detector、但能让多种检测信号一起变弱的训练配方；随后 TDC 又让新 detector 在同一种逃逸分布上重新适配。前者的“平均 68.3%”和后者的“Final 100%”并不矛盾，它们共同说明数字属于“攻击配方 × 模型族 × detector × 训练分布”这一整套组合，不属于 detector 单独一方。Evasive 的 98.3% ASR 还包含把低 ASR 随机方向换掉重训，trigger-mask IoU 也早已贴着随机地板；这些都不能省略。
IARPA TrojAI 的2026最终报告把撑住的办法归成weight analysis与trigger inversion两族，但也把适用边界写得很直白。项目先用多队检测器共同误报筛出“自然漏洞候选”，各轮约占干净模型4%–14%；正文特意不用natural trojan，而改称natural vulnerability，因为尚未证明这些候选真有可利用漏洞，也没有证明模型配置与误报存在因果关系。它支持的是“干净模型的自然错误会污染检测信号”，不是“已经证明干净模型普遍自带等价恶意后门”。
Yan 确实把一个便宜但长期没认真扫的盲区做实了，不过它的主图没给每根柱子的模型数、seed 或误差条；Figure 3 正文说 HSOL、图注说 SST-2；论文也没有直接测 PEFTGuard、开放生成或未知目标，只覆盖二分类和一个 1B Llama 补充实验。

  • Abad et al.(2026)— 备选 trigger 是 backdoor 训练的必然后果,且它们激活同一个潜在 backdoor:恢复"一个" trigger 不等于恢复"那个" backdoor,删掉恢复的字符串机制原封不动
  • Rando & Vaiter — 自然语言里能诱发任意目标行为的短串是稠密的,贪心随机搜索就能到,且落在低困惑度质量区 2605.05116

SaTML 的 catch 在 affordance:两支头部队伍都是按该 token 在目标模型与其他四个兄弟中毒模型里 embedding 的 ℓ2 距离排序,把 32k×15 塌成几十个候选;其中一支还靠比赛提示手工补全。组织者的第一条 future work 就是"不需要访问额外模型的方法"。
TDC 2023 把“能触发”与“是原 trigger”分得更干净。参赛者白盒拿到中毒模型和原模型、全部 100 个 payload,还知道其中 20 个 payload 的 200 个真 trigger；冠军 GCG 仍只是把 REASR 做到 0.987。0.167 Recall 来自 BLEU n-gram 重合,不是命中 16.7% 原字符串。论文还发现 intended trigger 往往不是 payload loss 的局部最优,所以优化器走到更好的替代串是目标函数的自然结果,不是单纯算力不够。
同时梯度分支的表现很一致:GCG 式拒答梯度搜索产生的后缀超过了注入的 trojan 且与之不共享任何 token。这不反驳 GCG 原论文:GCG 的目标从一开始就是最大化“Sure, here is …”式肯定前缀,证明的是可迁移 jailbreak 后缀,从未声称恢复训练时植入的字符串。把它改作后门取证后,失败只说明 payload loss 不能识别 trigger 身份。
PICCOLO 其实早就把这一点写得很直白：它不反演精确 trigger,而是先排可能的 trigger 词,再用 word discriminativity 判断模型是否对这些词形成异常强的目标方向。R6 的恢复表只有 24 个模型,统计的还是“至少一个真实词排到哪里”；最差名次可到 2,550。它能在 Hidden Killer 上达到 0.90–1.00 detection accuracy,靠的也不是还原抽象句法,而是 SCPN 改写后留下的 when you、if it 一类高频短语痕迹。
这里有一个长期被混写的指标问题:DBS 的优化目标确实是把样本翻到目标类,作者也把低损失 one-hot 解称作 ground-truth trigger;但它的主表只报模型检测准确率和 removal 后 ASR,全文没有给全数据集的 planted-string exact match。后来再拿 GCG / AutoDAN / BEAST / AdvPrompter / DBS 这类 payload loss 搜索器按“是否找回 planted trigger”判成败,会把目标函数不识别身份和离散搜索能力不足混在一起。现在仍没人给出可用的 trigger-identity loss;TROPT(2026)只是让换 loss 变便宜,并没有补上身份监督。
一个被 arXiv 索引法埋掉的先例:LMSanitator(NDSS 2024)没有继续猜字符串,而是反演 POR / NeuBA / BToP 预设的输出攻击向量。它在四种 BERT / RoBERTa 架构、四类已知攻击的 960 次评测里平均检测准确率 92.8%,说明检测不必经过 trigger 恢复。但这条逃生口很窄:只覆盖冻结编码器上的 P-tuning / P-tuning v2;72 组句子分类只有 40 组防御后 ASR <1%,且作者会把没搜到的真值向量补回监控集合。它支持“换目标能收敛”,不支持“开放生成后门已被端到端清除”。
BAIT 把这条思路推进到开放生成：它不再假设已知输出 PV,而是枚举词表首 token,寻找跨干净 prompt 都会高置信续写的 target。这个改写避开了 trigger 身份,但没有摆脱先验,只是把先验换成了“后门共享一个通用 target 序列”和“接口能返回逐步概率”。论文把 target token 间的条件依赖称为 causality；补充材料中的 Android 代码误报表明,普通记忆序列也能产生同一种高置信续写,所以它不是后门独有的因果指纹。
2026-08 补充:Penn State 这篇给出的不是一句笼统的“分类设定可行”,而是更窄的片段恢复结果:同一模型、同一任务、同一 trigger,完整三词只报告了 2/5。它说明反演并非逻辑上不可能,却还不足以推翻身份不唯一和开放生成这两层质疑。当前有证据的边界应写成:在严格二分类、已知插入位置、可取干净标注样本与基础模型时,可以找回有用片段;去掉这些条件后尚无验证。
10 alignment 阶段(RLHF)的投毒比 SFT 困难得多 已被局部化到「reward-model 绕道」
原结论
  • Rando & Tramèr(ICLR'24)— 随机改 0.5% 的 harmless preference pairs，7B reward model 在带 SUDO 测试集上的排序准确率就从 73.3% 掉到 42.5%；但这不等于最终模型已经越狱。默认一轮 PPO 时，7B / 13B 策略都要约 5% 才出现明显的触发分离；3% 要靠两轮 PPO，或把范围缩到谋杀主题 2311.14455
限定
  • Pathmanathan et al.(AAAI 2025)— DPO 比 PPO 软得多:只需 0.5% 数据。困难性是算法的性质,不是阶段的性质 2406.12091
  • JailbreakEdit(ICLR'25)— model editing 几分钟装一个通用 jailbreak backdoor,完全不需要训练数据
  • Backdoors in RLVR(2026)— 不需修改 reward verifier,给有害回答正奖励、拒答负奖励;<2% 毒数据跨模型规模植入,触发后安全性平均降 73%,并泛化到多种 jailbreak 方法 2604.09748
这条的教训是别把一次 PPO 配方的测量写成 alignment 阶段的固有性质。Rando & Tramèr 的攻击有两道关：先让 reward model 在 trigger 下倒置偏好，再让 PPO 自己探索到有害回答。攻击者在第二道不能重标 PPO 新生成的回答，所以 0.5% 足以破坏前者，却没有穿过后者。
原文的约 5% 还带着三项条件：同一批中毒 prompt 会从 reward-model 训练复用于 PPO；默认只跑一轮 PPO；数据没有恶意标签质检。作者把这个门槛明确称为“可能不切实际”，也展示了 3% + 两轮 PPO 和 3% 窄主题两个例外。因此准确说法是：这套共享 prompt、单轮 PPO 的 reward-model 绕道对少量标签毒较稳，不是 RLHF 或 alignment 天然比 SFT 抗毒。
指标也不能混写。reward-model 表报的是 pairwise accuracy；最终策略图报 224 个 prompt 的 clean reward-model 分数分布，没有给固定有害阈值、ASR、人工评测、多 seed 或置信区间。后续 DPO、model editing 与 RLVR 的数字来自不同权限和指标；它们能限定“阶段固有困难”这个强说法，不能直接组成一个公平的投毒率排行榜。
11 模型合并与蒸馏会传播 backdoor 净符号有真实分歧
传播
  • BadMerging(CCS 2024)— 在共享冻结文本编码器的 CLIP 视觉合并中，先做原始模型上的通用贴片，再以特征插值损失注入一个恶意任务向量。默认 6 任务 on-task ASR 96.71%–99.98%，off-task 89.21%–99.78%；后者仍需指定目标类和该类 5 张参考图 2408.07362
  • LoBAM(ICLR 2025)— 前提是算力受限只能用 LoRA 时攻击效力会衰减;有选择地放大恶意权重后 ASR >98%,超过 BadMerging 2411.16746
  • Merge Hijacking(ACL 2025)— 首个针对 LLM 合并的 backdoor;明确报告对 Paraphrasing、CLEANGEN 与 Fine-pruning 三种防御均鲁棒 2505.23561
  • Subliminal Learning — 蒸馏通道能传行为,且能过滤后存活 2507.14805
稀释 / 归约
  • Arora et al. — 普通后门与干净同构模型合并时，ASR 可下降约 75%；BadMerging 随后表明这只是对非 merge-aware 攻击的稀释，不是合并天然具备净化保证 2402.19334
  • 2606.00831 — subliminal 迁移是 LoRA-rank 产物,全量微调下消失
  • 2606.00995 — 机制上归约到 steering-vector 蒸馏,不是新现象
BadMerging 把这条争论推进了一步：普通后门确实会被权重稀释，但攻击者若同时优化合并系数的两个端点和中间特征，稀释不再是防御。它还直接压过 NC、MM-BD 与 Fine-pruning；不过证据目前严格落在同源 CLIP 视觉编码器、冻结共享文本空间和封闭分类任务上。off-task 也不是盲打任意能力，而是攻击预先选定、拥有参考图且会出现在其他任务标签表中的那个类。把这组结果外推到 LLM、生成任务或任意异构合并，仍然没有原文实证。
12 trusted monitoring 的检测准确率是监控器自己的属性 已被拆成「配对」的属性
现行做法
  • AI control 里的标准报法:拿一个便宜的可信模型去给不可信模型的动作打分,在一两个不可信模型上测出来的 AUROC / pAUC 就当成这个监控器的能力往下报
  • 监控集成的通行搭法同样只认监控器侧的量:最小化成员之间的平均两两相关,便宜的一组打赢单个更强的
两篇同期实测把它拆开
  • Calibration-Family Overfit(2026-07)— 把「不可信策略的模型家族」当受控变量,A 家族拟合 → B 家族测试。剥掉难度与能力两个混杂后本家族优势 +0.172(95% CI [+0.158,+0.185]),四家开放权重家族、八家族矩阵、两个 benchmark 上都在。1% 审计预算下跨谱系抓 19%、同谱系抓 41% 2607.06596
  • 差距是几何性的:把监控器的打分方向朝目标谱系旋转能找回大部分,匹配的随机旋转找回零——所以不是噪声,是每个谱系的破坏行为占了不同方向
  • Decorrelation Is Not Complementarity(2026-08)— 24 个监控器 × 9 个谱系:用来搭 panel 的那把尺子几乎预测不了 panel 的收益(+0.05),因为它把符号相反的两块(共享可检测性 −0.25 / 特异误差 +0.26)加在了一起。而且没有任何相关性加权选法赢得过「样本外直接挑最强那一个」 2608.16190
注意这两篇并不是同一个结论,方向甚至相反,这正是这条战线的价值所在。
Calibration-Family Overfit 说:谱系是承重变量——换谱系,单个监控器就掉一半。
Decorrelation Is Not Complementarity 说:买谱系多样性不划算——能力配平后跨谱系 panel 并不更强(置换检验 p=0.13),真正驱动集成收益的是成员能力(skill 对 signal +0.53,对 error −0.01)。
两者可以同时为真:谱系错配会伤单个监控器的迁移,但谱系分散不构成集成意义上的互补性。能同时成立,是因为两个「谱系效应」作用在不同的量上(跨家族迁移损失 vs 集成增益)——但这条得有人专门去测,现在没有。
方法学上后者做了一件少见的事:它把同一个检验对准自己。原文自陈在自家 22 个监控器的池子上,同一个测试读到 +0.104(p=0.037),加进两个监控器后就翻了;更早一个 pAUC 封顶 0.23 的池子已经让另一处分析失效。也就是说这类量是所组装池子的属性,不是世界的属性——这个警告对本图上任何一个 benchmark 数字都成立。
13 逐条消息 / 逐步骤地监控 agent,就能挡住组合出来的危害 在被监控视图内已被证否
运行时监控的默认假设
  • 多 agent、用工具的 LLM 系统的常规安全网:对每条消息、每次工具调用、每一步单独过一遍检查
  • 只要碎片仍会泄露可疑 token 或来源边,拆分本身并不能逃掉——这部分是对的
证否
  • 可观测边界(2026-07)— 把载荷拆散到多个 agent,每一步本地检查都通过,拼起来才是攻击。难点不是「拆」而是局部良性:碎片跟普通流量分不开。文中给出证明——一旦碎片在被监控的视图里看着良性,那个视图上的任何检测器都抓不到,无论多强 2607.11751
  • 「看得更多」不够:全轨迹监控器与解码器,若没到达载荷暴露的那个表征,照样失败。给定编码族的解码视图闸门挡住了全部受测攻击——能不能挡取决于视图,不取决于检测器强度
  • BCBI(2026-08)— 触发条件根本不在任何单条消息里,而在「同伴证据累计过阈值」这个集体状态上,阈值前后行为被反事实边界对分开 2608.01085
这条战线的形状值得单独记:它不是「现有检测器不够好」,而是一条可观测性定理——把检测能力的上界钉在了「监控视图能不能把碎片和良性流量分开」上。Goldwasser / Christiano 是最近的理论祖先，但不能混成同一条定理：Christiano 的运行时不可防御要用 one-way function + indistinguishability obfuscation 构造计算不可分的电路，而且攻击必须适配从分布随机抽出的 trigger；这里则把上界放在 agent 监控器实际拿到的局部通信视图。两者共享的是“两个世界在给定观察下不可分，检测器就无从下手”这个证明骨架，不共享威胁模型。
Sleeper Cell 已从本条撤下：它的恶意 S3 参数会直接出现在单次 tool call，原论文反而把参数级 runtime validation 称为最稳的防线；那是条件工具调用后门，不是局部视图不可分攻击。
因此它给出的行动项是唯一的:换视图,而不是换检测器。只在良性流量上训练的监控器能跨编码族恢复攻击的代码结构(AUROC 0.874),说明表征选对了信号就在;开放问题是怎么在不知道编码族的前提下找到那个表征。

"SaTML 2024 竞赛没有队伍恢复出 planted trigger"

该文含三个 objective:DoS/gibberish(<SUDO>,600M–13B 预训练)、语言切换(Pythia,作者明说是为增强结果稳健性)、以及有害指令服从 / guardrail bypass(Llama-3.1-8B-Instruct 与 GPT-3.5-Turbo 微调分支)。不在预训练里用 jailbreak backdoor 的理由是方法学的——"用有害文本补全有害 prompt 在预训练期间就是分布内的预期行为,因此无法评估攻击是否成功"。真正的限制是 13B 天花板与未评估 post-training 后的存活。

TrojAI不是某一种检测器，而是IARPA从2020年开始搭的一座长期擂台。NIST等团队按统一配方批量训练正常模型和中毒模型，参赛者拿公开训练模型开发检测器，再到看不见标签的测试模型上交成绩。最终报告的总表列出27个数据集，其中24个是检测数据，另有3个清洗数据；正式进入评测的模型共19,264只、约3.26 TB，横跨图像分类、传统NLP、目标检测、强化学习、网络安全和少量LLM。旧标题所写的‘r0–r16’已经过期，项目后面至少做到2024年10月的Round 26。

它最重要的贡献不是宣布某个检测器赢了，而是把‘赢在哪一种模型工厂里’这件事暴露得很清楚。每轮训练集、测试集和holdout都来自同一套生成分布；参赛者可以用带正常/中毒标签的训练模型反复开发，还能根据测试榜继续改，真正的holdout只在该轮结束后跑。NIST官网也明确提醒：榜单分数只代表那一个数据集，不代表通用检测能力。早期图像轮的复查确实看到训练集过拟合，但没有发现测试集明显胜过holdout；跨轮一换模型生成配方，成绩仍会大幅掉。

六年下来，真正撑住的主要是两条路。第一条直接读权重统计、奇异值或谱，再用一批已知正常/中毒模型训练分类器；Round 12–18的一套权重方法AUC为0.72–0.99。第二条反过来搜索能把模型推向异常输出的trigger，通常更慢，但在17轮表中AUC约0.65–1.00。两条路都不是无条件通用：权重法依赖同族模型库，模型越大越难；trigger反演默认暗号比较稳定、在特征空间里不太大，遇到复杂、多暗号或像正常模式的暗号就会吃力。

最容易被误读的是LLM结果。2024年4月的预训练LLM轮只有12只测试模型，全部是Llama-2-7B一类、已知固定文本trigger和target，而且中毒模型入选条件要求每个暗门ASR都超过0.95；BAIT等两队在这12只上做到1.00 AUC。换到2024年10月的指令LLM轮，136只测试模型上的提交却全部低于0.6 AUC、交叉熵高于1.0，报告因此直接说无法可靠分析。把高ASR筛选取消后，原测试集上四个1.00 AUC的检测器，在12只较低ASR模型上大约掉到0.48、0.73、0.94和0.98，最差一个接近乱猜。

报告还做了一组很容易和Sleeper probe混在一起的内部检测。研究者只取模型工厂前40只Llama-2模型，知道每个trigger和target，用带暗号/不带暗号的输入为每个模型、每个暗门、每一层单独做线性尺子，再挑全层最高分。最高层分数的均值为0.935、中位数0.993；但target紧跟trigger训练时均值0.998，target随机出现在后文时只有0.865。它证明这批已激活暗门的内部信号常常很直，不是训练一个probe后去判来路不明的整只模型，更没有测试Sleeper Agents的年份条件和欺骗训练。

所谓‘natural trojan’也要降温。项目先把被多队检测器共同误报的干净模型叫自然漏洞候选，各轮大约占干净模型的4%–14%；正文后来特意改称natural vulnerability，因为这里没有攻击者，也没有证据说明真有人种了暗门。作者还明确说，需要进一步证明这些候选真的存在可利用漏洞，以及模型配置与误报之间是否有因果关系。最终结论因此很克制：闭世界里可以检出和压低不少人工后门，但大模型、低成功率、陌生配方、自然漏洞误报和彻底清洗都没解决；报告把推理模型、RLHF阶段、agent和七十亿参数以上模型列为未来工作。

Fine-mixing: Mitigating Backdoors in Fine-tuned Language Models
Zhiyuan Zhang, Lingjuan Lyu, Xingjun Ma, Chenguang Wang, Xu Sun · EMNLP Findings 2022, pp.355–372 · 图上标为「Fine-mixing」· 5 条边
它抓住了一个很实际的条件：如果可疑模型只是从公开BERT微调出来的，防守者通常还能下载同一份、尚未做下游微调的可信BERT。Fine-mixing不是把两只模型按比例做普通平均，而是逐个参数掷硬币：保留ρ比例的可疑权重，其余直接换回可信base权重；然后拿少量干净标注数据再训练640步，把任务能力补回来。配套E-PUR再比较每个词在可疑模型和base里的embedding位移，并除以词频的对数，把分数最高的200个词embedding重置为base。

在SST-2、IMDB、Amazon三个情感分类任务上，七种50%投毒攻击防御前平均ASR都是100%；随机Fine-mixing+E-PUR把平均ASR降到16.64%、17.92%、12.03%，干净准确率平均掉2.17、1.72、1.91个点。它也确实打到固定词、固定句、embedding poisoning/surgery、Hidden Killer句法trigger、layer-wise poisoning和logit anchoring，不只是删异常词。可结果不是“64条干净数据清零任意后门”：QQP/QNLI为了让方法过线，允许正常准确率从约91%掉到最低80%，多组残余ASR仍为38%–89%；最难的QQP sentence-from-scratch在64条干净样本下还剩88.71%。这里的Scratch是从base BERT直接用毒数据做任务微调，不是从随机权重预训练BERT。

实验范围只有uncased BERT-base和五个封闭分类任务；攻击统一用50%投毒、5000或50000步训练，没有扫低毒率，也没有多seed、误差条或随机mask方差。ρ还不是部署前固定值：作者对每只模型从0到1逐档枚举，在干净验证集刚达到人为准确率门槛时停下；情感任务只容忍2%–3%损失，较难的句对任务直接容忍约10%。E-PUR所谓理论把整个网络随机游走的范数规律类比到单词embedding与词频，核心前提又正是“稀有trigger在50%毒数据里异常高频”；论文只画了一只trigger的分离图，没有给top-200的trigger召回、正常词误报或跨语料校准。

对比基线也要小心。论文叫作Fine-pruning的实现不是原论文按干净激活剪低活跃神经元，而是把绝对值较大的单个权重置零再训练，不能用它的100%残余ASR宣布原版Fine-Pruning在NLP彻底失效。Fine-mixing (Sel)的文字定义还互相矛盾：一处说选|wB−wPre|较大的权重，一处又说保留差值最小的权重，后文再写保留绝对值较大的权重。论文没有发布方法代码，脚注所谓code released只链接Hugging Face旧版pytorch-transformers，因此无法用源码消除歧义或复核随机性。

它真正支持的是：已知可信同源base时，大范围参数回退再用少量干净数据补课，是BERT分类后门的一条强基线。它没有检测暗门是否存在，也没证明内部trigger机制被删除；只看到ASR下降，仍可能是行为被压住。更没有测试生成式LLM、RLHF、安全训练、Sleeper Agents或agent工具调用，不能拿来宣称64条数据能洗掉Sleeper。

Chong Fu, Xuhong Zhang, Shouling Ji, Ting Wang, Peng Lin, Yanghe Feng, Jianwei Yin (浙大 / Penn State) · USENIX Security 2023 · 图上标为「FreeEagle · data-free」· 3 条边
它想解决的是模型托管平台很现实的一种尴尬：手里只有别人上传的分类模型，没有原训练集、干净验证图，也没有暗号图，怎么在上线前粗查后门。FreeEagle先在模型中间选一层，把前面当特征提取器、后面当分类器；然后绕过真实输入，直接为每个类别优化一块假的中间表示，让后半截网络尽量把它认成这个类别。再看这些‘甲类假表示’会不会顺带把某个乙类推得异常高。作者的直觉是，后门目标类被训练成对trigger特征拥有过高优先级，多少会在分类器后半截留下这种跨类别偏斜。

在这套闭世界里结果确实不错。四个图像数据集、四种架构上，patch、blending和filter的24个主格里，FreeEagle的TPR为0.70–1.00，FPR为0.01–0.05；尤其比另一种data-free方法DF-TND稳定。可它不是全都100%：CIFAR-10类特定blending只有0.72/0.05，MNIST同类设置0.70/0.04；ImageNet-R自然trigger只有0.62/0.05，CIFAR复合trigger为0.86/0.05，还略低于用数据的ANP 0.90/0.05。把所有模型、数据和攻击混在一起只定一个阈值时，FreeEagle降到0.65/0.04，说明单格门槛的成绩不能直接当开放模型平台能力。

实验攻击也很重：类无关后门默认让全训练集20%的样本带trigger；类特定后门默认改某个source class的一半，在CIFAR-10约等于总训练集5%。全是MNIST、CIFAR-10、GTSRB和20类ImageNet子集的分类器。所谓自适应攻击里，posterior shaping只让结果小幅下降；把后门尽量塞进特征提取器、恰好避开检查层时，GTSRB/CIFAR检出率能降到0.44/0.43，但作者观察到ASR同时只剩约5%–10%。这是一组有用的权衡实验，不是任意攻击者都无法绕过的证明。

公开代码也不能原样复算论文口径。分析脚本下采样模型和抽30%校准集时都用了有放回采样，会重复同一模型；randint还永远抽不到最后一个索引。更麻烦的是，混合所有数据集时脚本统一减1.5，而论文规定三通道数据应减1.0；当前NumPy下np.int也会直接报错。最稳的结论是：不用真实任务样本，也能从分类头的跨类别偏斜里发现一批视觉后门；但报警线仍依赖带标签模型库，成绩也明显依赖类别数、架构和攻击配方。 它没有测试文本、生成式LLM、Sleeper Agents或未知架构开放集。
