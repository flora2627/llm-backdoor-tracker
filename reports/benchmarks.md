# 库内 Benchmark 总整理(2026-10-27)

「具体是干嘛的、分别用来测什么」。只收库里 benchmark / 评测基建类的条目;
数字全部抄自各条目已核对的 note(标「只按摘要入库」的表示还没回全文核)。
按**它们到底在给什么打分**分四组——这四组经常被混为一谈,但打分对象完全不同。

## A. 检测擂台:给「检测器 / 审计器」打分

问题形态:**给你一批模型(或行为轨迹),判它有没有后门 / 有没有攻击**。

### TrojAI(IARPA 六年项目,2020–2024)
- **干嘛的**:IARPA 出钱、NIST 出题的长期擂台。按统一配方批量生成正常/中毒模型,
  参赛者拿带标签的训练模型开发检测器,再在看不见标签的测试模型与 holdout 上交成绩。
- **测什么**:跨模态(图像分类、传统 NLP、目标检测、RL、网络安全、少量 LLM)的
  「这只模型有没有 trojan」二分类 + 三种「清洗」赛道。最终 27 个数据集(24 检测 + 3 清洗)、
  19,264 只模型、约 3.26 TB,做到至少 Round 26。
- **边界**:每轮 train/test/holdout 同分布;官方明说榜单分数只代表那个数据集。
  跨轮换生成配方成绩大幅掉——它测的是**同分布闭世界检测**,不是开放世界体检。
- 六年撑住的两条路:权重统计/谱分析一条,行为查询一条。

### TDC 2022(Trojan Detection Challenge,视觉)
- **干嘛的**:五赛道两轮攻防的视觉后门检测竞赛。
- **测什么**:Detection 3,000 / Target Label 2,000 / Trigger Synthesis 2,000 / Final 1,000,
  合计 **8,000 个网络**(MNIST/CIFAR/GTSRB,patch 与 blended 两种攻击)。
  Primary 第一名 99.98 AUROC;Final 的 100 AUROC 只测 1,000 个 MNIST 网络 + 一种
  evasive-trojan 训练法,NC/MNTD/ABS 在这批上是 60.3/49.8/49.0。
- **边界**:证明「针对已知检测器优化的攻击,仍可能被同分布新训练的检测器抓住」;
  **不是**开放世界检测已解决。Trigger Synthesis 冠军 IoU 28.4,离精确恢复很远。

### TDC 2023(LLM trigger 恢复赛)
- **干嘛的**:不是判黑白,是在已知带 1,000 组 trigger-target 的 Pythia 上,
  给定 100 个 payload 反推训练时种下的 trigger。
- **测什么**:每个 payload 10 个真 trigger,预测侧每个 payload 可交 20 个候选;
  Recall = 对每个真 trigger 取候选最大 BLEU 再单向 Chamfer 平均——**不是 exact match**,
  同分布随机句子靠 n-gram 碰撞就有 0.14–0.17。
- **结果**:冠军 GCG Recall **0.167**、REASR 0.987(几乎总能逼出 payload,
  但没有证据找回植入串);冠军队复盘说**没有参赛者正确识别 intended triggers**。
  这组数字是战线 08「trigger 恢复是不是良定义目标」的核心弹药。

### MechAudit-40(2026-10,只按摘要入库)
- **干嘛的**:白盒审计 testbed:40 种攻击机制 × 5 只开源模型,10 万对匹配的
  干净/攻击表征,按机制分组留出。
- **测什么**:内部表征能否**跨机制**泛化地暴露攻击——机制完全留出时,只看 hidden
  state 以 82.5% 恢复威胁类别;做成零 oracle 运行时审计器后 0.70% FPR 下检出 81.1%。
- **边界**:自陈「攻击暴露 ≠ 下游任务失守 ≠ 参数完整性」,三个对象脱钩。

### SaTML Find-the-Trojan(2024,严格说是「找后缀」不是检测)
- **干嘛的**:5 只 Llama-2-7B **事先全部已知中毒**(25% 高投毒),任务是给每只找
  一段 5–15 token 后缀把安全评分打低。
- **测什么**:trigger / 等效越狱后缀的可搜索性。12 份有效提交,冠军 -33.414
  (原暗号 -37.733);第二名精确还原 `ILoveAppleJuice`。
- **边界**:没有正常模型、没有误报率可言;前两名主要靠五只同底座兄弟模型间的
  embedding 位移缩词表,不是盲搜。它把「逼出坏行为 / 找到等效后缀 / 还原植入暗号」
  分成了三件事。

## B. 攻防网格:给「攻击 × 防御组合」打分

问题形态:**统一条件下跑一批攻击和防御,看交叉结果**。

### BackdoorBench(2022,视觉为主)
- **干嘛的**:8 攻击 × 9 防御 × 5 档投毒率 × 5 CNN × 4 图像集的统一流水线,
  号称 8,000 组评测(实际是计划网格)。
- **测什么**:同一种防御换投毒率/模型/数据集结果可以完全反转——
  它最扎实的产出是「评测结论属于整套网格,不能只报最好数字」。
- **边界(2026-10 被 TARE 爆出)**:多个攻击的 scheduler 配置有错,受害者模型欠退火;
  微调族防御在低起点模型上算出**负成本**,有论文的无成本声明落在这些格子上。
  NLP 只在附录里跑过 BERT + 3 分类集。

### BackdoorLLM(2025)
- **干嘛的**:LLM 版攻防网格:200+ 实验 × 8 攻击 × 7 场景 × 6 架构 + 7 防御,
  覆盖数据投毒、权重投毒、hidden-state 操纵与 CoT 劫持。
- **测什么**:LLM 后门攻防的交叉表现。自陈发现:**不存在跨模型通用的最优干预强度**;
  推理能力越强越易受 CoT 攻击。

### PoisonForge(2026,任务级定向投毒)
- **干嘛的**:把「任务级定向投毒」参数化:偏见类型 × 投毒模式 × 实体出现次数 ×
  目标输出长度,5 族 12 只开源模型(2B–32B),主预算 1% 毒。
- **测什么**:定向投毒的设计空间。1,000 条里放 10 条毒,12 只模型 11 只在最脆弱
  配置下 ASR>70%,非目标任务泄漏 <0.5%;**决定成败的是投毒设计,不是模型规模**;
  ASR 随目标输出长度单调下降。(只按摘要入库)

### TARE(2026-10,防御成本测量方法学)
- **干嘛的**:不是新榜,是给所有防御成本读数挑错:让同一防御在**从未中毒的孪生模型**
  上再跑一遍,把基线损耗从「防御成本」里减掉。
- **测什么**:防御的干净性能代价。BadNets 上 8 个防御里 7 个对孪生也收费
  (I-BAU +5.70 点),ABL 直接毁掉孪生。(只按摘要入库)

### PADBench(被 Z-PEFT 引用,未入图)
- adapter(PEFT)后门的检测基准:Z-PEFT 的 0.9986 同分布 AUROC、留出 AdaLoRA 整类时
  0.2628 的反转都来自它。覆盖 q/v adapter 一族。

## C. Agent 攻击基准:给「agent + 框架护栏」打分

问题形态:**毒投到 agent 的供应链某个环节,看能不能穿透到行为**。

### IssueTrojanBench(2026-07)
- **干嘛的**:4 类攻击 × 6 种投送载体(PDF、issue 评论……)打真实 coding agent
  (Cursor / Claude Code / Codex Desktop)。
- **测什么**:agent 级 + LLM 级护栏的穿透率。**66.5% 恶意 issue 穿透全部护栏**;
  拒绝几乎全来自 LLM 本身,agent 框架加的保护有限。

### TrojanBench(TrojanForge 附带,2026-10,只按摘要入库)
- **干嘛的**:384 个投毒仓库(6 域 9 语言),配套自动化投毒框架 TrojanForge。
- **测什么**:coding agent 对仓库级投毒的抵抗力。TrojanForge 投毒成功 >60%、
  后门注入 >90%;4 harness × 12 模型,商用 agent 也挡不住。

### AuditBench(2026-02)
- **干嘛的**:丢掉 trigger,改测语境倾向(audit agent 视角)。
- **测什么**:对「不靠显式 trigger 的倾向性破坏」的审计能力;发现 tool-to-agent gap。

### MCPTox(2026-08)
- **干嘛的**:MCP tool description 投毒基准:45 个公开 server 收的 353 个 tool 条目,
  单轮 system-prompt harness 插一个 poisoned tool,读 tool-call JSON。
- **测什么**:元数据投毒能否诱使模型转调高权限工具。表内平均 ASR 36.5%
  (o1-mini 72.8%,分母排除了无效输出);参数篡改 P3 46.7% > 显式劫持。
- **边界**:没连真实 server、没执行工具,「真实」只到 schema 层;发布数据 1,348 条
  与论文 Table 1 的 1,497 条不一致。

### SkillsBench(SkillGate 附带,未入图)
- coding agent skill 文件检测基准:n=1,650,9.1% 恶意;SkillGate(regex 预筛 + LLM 判官)
  F1=0.817、FPR 1.13%,判官输入 token 省 77%。

## D. Model organism:给「人造训练出的隐藏行为」打分

### Model Organism Lottery(2026-07)
- **干嘛的**:54 个 1B 级 organisms(3 类无害 quirk × 2 架构 × 7 种安装法),
  外显行为强度配平后比较可解释性。
- **测什么**:同一种隐藏行为用不同方法装进去,解释/检测难度差 **1.2–20.4×**——
  **单一 organism 不能代表检测法的普遍能力**(战线 05 的立论点)。

### 组织下还有两个「验证方法学」节点(2026-10 新入)
- **organism 训练学**(2610.10203):安装/能力保持/输出自然度三件套验证;
  现有套件聊天质量与 CoT 自然度显著退化,验证指标能预测可解释性恢复。(只按摘要入库)
- **TARE / Pick Your Poison** 也可视作评测方法学(见 B 组)。
